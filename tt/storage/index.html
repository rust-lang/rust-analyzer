Module storage 

Source
Expand description

Spans are memory heavy, and we have a lot of token trees. Storing them straight will waste a lot of memory. So instead we implement a clever compression mechanism:

A TopSubtree has a list of CompressedSpanPart, which are the parts of a span that tend to be shared between tokens - namely, without the range.

The main list of token trees is stored in a variable-length encoding as bytes. The encoding is documented in the decode() function (which decodes one TokenTree).
